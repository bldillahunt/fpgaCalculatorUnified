FPGA Fixed-Point & IEEE-754 Reference Guide

Deterministic bit-accurate hardware math emulator for Verilog, VHDL, and embedded DSP workflows. Convert between signed decimal, 2's complement binary/hex, Q-format fixed-point, and IEEE-754 floating-point representations.

Data Formats & Radix Point Rules

  • REAL (Signed Decimal): Standard base-10 values (e.g., -12.625, 3.14) converted to exact hardware bit representations.
  • HEX (2's Complement Integer): Hexadecimal inputs and outputs do not use a radix point. When converting a fractional result to HEX, check the Q-Format readout to see the implied radix point position.
  • BIN (Binary with Radix Point): Supports an explicit binary point (e.g., 101.11). Operands in an expression can have different integer and fraction bit widths—the engine aligns them automatically.
  • FP32 & FP64 (IEEE-754 Hex): 32-bit single precision and 64-bit double precision hex encodings for hardware FPU verification.

Supported Operators & Syntax

  • Arithmetic: Standard addition (+), subtraction (-), multiplication (*), division (/) and modulo (%).
  • Bitwise Logic: Hardware bitwise AND (&), OR (|), and XOR (^).
  • Complements: Use ~ for bitwise inversion (1's complement) and ! for arithmetic negation (2's complement).
  • Clean Input Parsing: Spaces and 0x/0b prefixes are stripped automatically. Example: 101.11 * 010.01.

Q-Format & Division Precision

  • Automatic Width Sizing: Addition, subtraction, and multiplication preserve full bit accuracy across operands with mismatched integer or fractional widths.
  • Fraction Bits Setting: Used primarily to set the output fractional precision (LSB resolution of 2^(-N)) for division (/) operations and decimal conversions.
  • Q-Format Readout: Displays the resulting QM.N format (M integer bits, N fraction bits) so you know exact bit-slicing boundaries for Verilog/VHDL registers.
